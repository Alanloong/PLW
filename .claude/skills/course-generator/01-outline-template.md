# 课程大纲模板

> 根据项目特点和用户画像，定制生成

---

## 大纲结构

```
模块一：认知建立
- 第1课：项目初识 — 了解项目是干什么的
- 第2课：核心概念 — 搞懂关键术语

模块二：结构认知
- 第3课：项目结构 — 文件都是干嘛的
- 第4课：核心文件 — 精读最重要的文件

模块三：深入理解
- 第5课：[核心机制一]
- 第6课：[核心机制二]

模块四：总结实践
- 第7课：总结与实战
```

## 不同场景的调整策略

### 快速上手场景
- 偏重概念解释和用法介绍
- 减少技术细节和代码层面的内容
- 每课内容精简，注重"知道就行"
- 课时：5-6课

### 学习原理场景
- 增加设计模式分析
- 对比不同实现方案
- 注重"为什么这样设计"
- 课时：7-8课

### 掌握代码场景
- 增加代码走读环节
- 每个重要文件单独解读
- 需要用户跟读代码
- 课时：8-10课
