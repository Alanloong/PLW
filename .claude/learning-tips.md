# 学习 GitHub 项目的技巧

## deepwiki 速览法
学习 GitHub 上的开源项目时，将 URL 中的 `github.com` 替换为 `deepwiki.com`，可以快速获取项目的深度分析，包括：
- 项目概况与背景
- 目录结构说明
- 核心架构设计
- 关键技术细节
- 优缺点分析

### 示例
```
原地址：https://github.com/MadsLorentzen/ai-job-search
替换后：https://deepwiki.com/MadsLorentzen/ai-job-search
```

先通过 deepwiki 了解项目全貌，再决定是否深入阅读源码。
